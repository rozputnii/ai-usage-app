The operator session also has a `claude-code-remote` server (26 tools) from its host app; it is
not an account connector. `ENABLE_CLAUDEAI_MCP_SERVERS=false` removes every claude.ai connector
from `claude mcp list` and leaves only the `pdf-viewer` plugin server.

Drive files or change the calendar (a security boundary, absent on `second`); primary and
built-in subagent cold starts grow by the extra deferred tool names. The lean roles in
`D-agents.json` list their tools and should be unaffected.

Also seen, not an account difference: `installed_plugins.json` holds 103 project-scope
`csharp-lsp` entries for run clones under `C:\aiu-exp`, so `claude plugin list` repeats the
plugin about a hundred times. Harmless; not changed.
