## Problems found and fixed

- **Judge blinding** (fixed in `1e02943`): `Start-Judge.ps1` ignored `#anchor` and sent the whole
  brief file, so the smoke judge read the operator note naming arms D and A, and a replay judge
  would read every arm and every replay. `-Brief` and `-DefectKey` now take a `file#anchor`
  section; the pilot prompt carried no arm or other-replay text.
- **NuGet warm-up on this PC**: the user NuGet configuration has a second, private feed, so
  `dotnet restore` without `--source` fails with NU1507 (central package management with
  several sources). The warm-up used `--source https://api.nuget.org/v3/index.json`; the
  offline restore from verification.md then passes for every project. The host configuration
  was not changed. Runs follow the offline one-liner and are unaffected; an agent that restores
  without `--source` would hit NU1507, which counts as environmental.
- **Worktree**: the repository checkout was on `exp/eco-roles`, so it was switched to `main`
  before `git worktree add` (one branch per worktree).

## Notes for S2 and later

- The binding constraint is the five-hour session window (about $26), not only the weekly
  limit: S2's $130 needs at least five windows. The operator asks for the session percent
  before each batch and starts a run only when the window has room for it plus 10%; a run cut
  by the limit is invalid and reruns.
- RP1's defect key is RV1 in `micro-review.md`, a `###` heading without a `{#...}` anchor, and
  `Start-Judge.ps1` takes only `## ... {#anchor}` sections. Before S3, move RV1's key into a
  section the judge can take alone; the whole file would also show it the trial method and the
  other keys.
- Spend in S1: runs $1.27, judges $0.67, model and tool-list checks about $0.20, operator
  session about $4.5 (overhead, not counted in any arm). Plan estimate was $60.
