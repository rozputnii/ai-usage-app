# S2 results (in progress, new PC, account `second`)

Micro-trials, run in batches of at most $20 with `tools/Start-Batch.ps1` (random order, budget
stop). The owner sends the `/usage` reading with every message; readings are logged locally.

## Setup added for S2 (2026-10-11)

- `csharp-lsp@claude-plugins-official` 1.0.0 installed for the account (user scope; owner
  authorization 2026-10-11). Checked in a clone: a haiku run had the LSP tool and found
  `PeakHours` and its two usages through it. Runs before this point (S1, the runner batch) had
  no LSP tool; the runner trial does not use it.
- graphify 0.9.85 (`uv tool install graphifyy`; `graphify install` not run). The graph is built
  once per base outside the measured run with
  `graphify extract <clean clone> --code-only --out C:\aiu-exp\graphify\<base>` (local AST, no
  LLM, no semantic pass): 6 s for `1a8526e`, 4,956 nodes, 17,186 edges. Runs get it through
  `Start-Run.ps1 -CopyIntoClone C:\aiu-exp\graphify\<base>`, git-excluded in the clone.

## Runner (H3)

Base `1a8526e`, primary opus medium, `D-agents.json`; checks restore, C2, C6, C4, C5. Two runs
per variant, $0.78 in total.

| Variant | Cost | Primary calls | Subagent | Wall |
| --- | --- | --- | --- | --- |
| self | $0.22, $0.22 | 4, 4 | none | 0.8, 0.6 min |
| delegated (haiku `runner`) | $0.17, $0.17 | 2, 2 | 7 and 6 calls, cold start 7.7k, $0.004 | 0.7, 0.7 min |

All four reported every check PASS, and the logs agree (C4 926/926, C5 347/347, C2 valid). One
delegated run left no `C6.log` (empty output) while reporting C6 PASS correctly.

Result: H3 is **not supported** here: the haiku runner was 23% cheaper, because each opus call
it saves costs about $0.025 and the runner starts at only 7.7k tokens. The checks were quiet and
all passing; a failing check, whose output the primary must read anyway, may change this.
