# Product vision

**AI Usage** shows how much subscription quota remains for each AI account, context and model group, and when it resets.

Users get a native Windows dashboard, history and tray mini-dashboard. They connect accounts through the browser or supported CLI import while credentials and data remain on their machine. There is no AI Usage cloud account, substitution of API billing for consumer quotas, or fabricated overall AI usage percentage.

The development owner manages goals and reviews installable builds. OMP handles research, justified decomposition, execution, verification, repository state and authorized merges. The owner does not need to prompt every internal task.

Source code is public under MIT. Direct Windows distribution is free. A later Microsoft Store acquisition may be paid without creating separate paid features.

## Success
After bootstrap, a fresh root OMP session without the earlier chat understands the active goal, shows the queue or continues explicitly authorized Autopilot, does not reopen approved stack decisions and preserves work. After the Codex slice, the owner installs an MSIX, signs in and sees verified quotas. Other providers and richer UX follow incrementally.

## Not a promise
This vision does not verify provider access, third-party OAuth approval, a universal 500 ms launch time or package dependency compatibility. Those require explicit technical gates, fixtures, spikes and Windows measurements.

## Working language
All repository artifacts are English. Owner-facing conversation may remain Ukrainian.
