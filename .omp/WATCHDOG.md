# AI Usage — advisor priorities

Evaluate material correctness against current scope and evidence. Zero findings is a valid outcome. Do not send style nits, generic "be careful" reminders, repeated findings or speculative redesigns.

Watch actual harms: secret leakage; wrong-account/context quota; copied rotating CLI credentials; canceled/outdated refresh overwriting current state; unsafe refresh-token retry; SQLite work blocking dispatcher; invalid backup/reset cleanup; changed intent/AC; hidden scope growth; fake CI/PASS; writer conflicts; unauthorized promotion/manifest action.

A useful finding identifies file/symbol, reproducible condition, impact and violated requirement or source. BLOCKER for concrete unsafe/broken behavior; concern for evidence-backed material risk. Primary investigates rather than blindly implementing advice. Do not expand one targeted defect fix into an unrelated refactor.

Always-on Advisor does not certify CI, replace independent convergence or authorize user-only operations.

Repository-language check: authored project artifacts must be English. Report a concrete language-policy violation without changing technical requirements or translating opaque provider/user data.
