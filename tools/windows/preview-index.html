AI Usage
Development Preview

Test builds for Windows 11 24H2 or later, x64. These packages use a self-signed development certificate. They are not a publicly trusted release.

  1. Install the .NET 10 x64 runtime if missing. Windows App SDK dependencies are included in the install feed.
  2. Download the public test certificate. Verify its thumbprint against release metadata and the repository's recorded setup result. For a test device you control, import it into Local Machine → Trusted People. This requires administrator approval. Do not add it to Trusted Root Certification Authorities.
  3. Download and open AI Usage App Installer. Install through this file to subscribe to updates.

Each successful main push publishes a new Preview. Windows checks on launch and periodically in the background. Exit AI Usage from its tray menu to allow a pending update; closing its window only hides it. Windows does not forcibly restart the app.

The unpackaged developer build is separate from the installed app and is not updated by this channel. Provider credentials are not imported from it.
