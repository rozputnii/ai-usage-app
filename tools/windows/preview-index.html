AI Usage
Development Preview

Current version: {{VERSION}}. Windows 11 24H2 or later, x64. Builds are signed with a self-signed development certificate, not a publicly trusted one.

  1. Install the .NET 10 x64 Desktop Runtime if it is missing. The Windows App SDK runtime is installed with the app.
  2. Once per device, trust the test certificate:
    1. Download AiUsage.Development.cer and open it. Check that its thumbprint matches certificateThumbprint in release.json.
    2. Choose Install Certificate… → Local Machine → Place all certificates in the following store → Browse… → Trusted People → Finish, and approve the administrator prompt.

    Do not keep the automatic store choice: it puts the certificate under Intermediate Certification Authorities, where Windows does not accept it for apps. Do not add it to Trusted Root Certification Authorities.

  3. Install AI Usage:
    Install AI Usage
    Open the downloaded AiUsage.appinstaller and choose Install. Installing through this file keeps the app updated.

If App Installer cannot download the app, install the packages directly: first Microsoft.WindowsAppRuntime.2.msix if the Windows App SDK runtime is missing, then {{PACKAGE}}. A directly installed package is not updated automatically; install through the App Installer link later to subscribe to updates.

Each successful main push publishes a new Preview. Windows checks on launch and periodically in the background. Exit AI Usage from its tray menu to allow a pending update; closing its window only hides it.

The unpackaged developer build is separate from the installed app and is not updated by this channel. Provider credentials are not imported from it.
