# feature-delivery

Follow CONTRIBUTING.md: inspect relevant spec and evidence, state the result and acceptance checks, implement within scope, review the integrated diff and verify it. Use tasks.md only when useful for decomposition or handoff. On interruption record one exact next action. Do not infer authorization for another feature or remote action.

Report observed checks and limitations honestly. Preserve secrets and opaque user/provider data.
